# 拾要正式版界面重设计实施计划

确认日期：2026-11-13（北京时间）。用户已明确要求实施本计划。

## 1. 基准、目标与边界

- 从正式版 `codex/m3-integration-probes`（核对基准 `f60afbe`）建立 `codex/ui-redesign-warm`。实施前核对远端变化，保留已有正式功能和本机数据。
- 保留拾要名称和图标，采用米白、墨绿和少量暖金的温润个人助理风格；使用 impeccable 的 Operate 规范和 design-taste-frontend 改版检查。
- 沿用 C# WPF、WebView2、HTML/CSS/JavaScript，不增加运行时框架或在线字体。
- 覆盖任务、待确认、通知、已完成、回收站、设置、详情、表单、原图/OCR、两张桌面卡片和原生标题栏。
- 信息层级以标题、时间、来源、当前问题及下一步操作为核心，统一文字、间距、控件和状态。
- 全部列表继续按原消息时间倒序；优先级只影响展示和高亮。默认优先进入待确认。
- 日期/钟点精度、图片日期人工确认、完成一小时撤销、忽略二十四小时撤销、人工字段保护、版本/账号/代次隔离、合并拆分和历史均保留。
- 继续点击触发同步、游戏延后和普通 QQ 恢复；QQ 只读。Windows 系统通知、声音、自定义提醒时间和安静时段保持取消。
- 桌面卡片仅在桌面显示，不置顶、不抢焦点，无对应事项时隐藏。

## 2. 视觉规范

| 角色 | 浅色 | 深色 |
|---|---|---|
| 主背景 | #F5F3EC | #000000 |

| 主文字 | #25332D | #EAECE3 |
| 辅助文字 | #5F6B63 | #A7B0A4 |

- 主色用于选择和主要动作，暖金用于注意，红色用于错误/逾期/未读。状态必须同时有文字；正文与占位文字对比度至少4.5:1，控件和焦点至少3:1。
- 字体为 Microsoft YaHei UI、Segoe UI 和系统无衬线回退。页面24px、详情20px、事项16px、正文/表单14px、辅助12～13px，小按钮至少13px；正文行高约1.6。
- 间距4/8/12/16/24/32px；按钮/输入框36px、小按钮32px、确认40px；控件圆角6px、分组8px、桌面16 DIP。
- 160ms轻微反馈、事项悬停约1px位移、320ms换肤；尊重系统和应用减少动画设置；无逐项进场动画。
- 普通分区用留白、分隔线和背景区分，阴影用于浮层和轻微反馈。

## 3. 窗口与导航

- 保留原生标题栏及1000×620最小宿主窗口，测试扣除标题栏后的内容区；界面填满窗口，移除外围20px留白和整窗阴影。
- WebView可用宽度至少1200px时，导航208px、详情420px、内容内边距24px；较窄时导航168px、详情360px、内边距20px；列表使用剩余空间。
- 顶部约64px，左侧页标题与说明，右侧真实同步状态、自动同步、刷新；去掉重复面包屑/标题，日期为辅助信息。
- 导航分处理（任务/待确认/通知）、记录（已完成/回收站）、底部设置；实际计数与未读含义不混淆。
- 列表工具区固定，仅事项滚动；详情独立滚动，底部确认固定。较窄时搜索一行，筛选/新增下一行；按钮不折字。
- 设置占满内容区，隐藏详情栏。全局错误在顶部下方，字段错误靠近表单。
- 状态覆盖读取、等待、切换QQ、同步、恢复QQ、游戏延后、完成、部分未补全、失败；保留本地事项、错误和重试入口，不捏造进度。
- 刷新只取快照；导航、主题、图片和设置定位不触发QQ同步。

## 4. 列表与详情

- 任务保留新增及待办/归档/取消/全部筛选；待确认保留核对原因、建议日期和已有状态筛选；通知可转任务/查看关联任务；已完成与回收站保留对应撤销。
- 行结构：标题/未读/变更/优先级或状态；课程或来源/正式时间；必要时核对原因或建议日期。标题最多两行，详情完整；长来源可省略但完整内容可访问。
- 时间明确区分截止、开始和仅日期。选中浅墨绿，普通行弱边框，逾期/今天同时有文字；不按优先级另分组。
- 搜索、课程、状态组合；支持中文输入法。保留仍可见的选择，否则沿用首个可见项；空列表清除失效详情。
- 空状态区分无事项、搜索无结果、等待连接、读取失败；无结果可清除筛选。
- 详情顺序：标题/来源/状态；正式日期/变更/核对问题；事项操作；原文和图片；编辑/确认；关联/变更历史/合并拆分。
- 待确认原文默认展开；其他长原文六行预览并可展开/收起。逐条保留来源与时间，同事项刷新保留展开状态，新证据提示用户；OCR独立折叠。

### 待确认操作矩阵

| 类型 | 操作与限制 |
|---|---|
| 普通待办 | 确认并加入任务；正式日期必需，钟点可空 |
| 普通通知 | 确认并加入通知；无需任务日期 |
| 关联延期/新要求 | 确认并更新任务；校验目标及版本 |
| 关联取消 | 确认取消关联任务；无需补日期 |
| 关联催交 | 确认并更新任务；未填新日期时保留原时间 |
| 无目标延期/补交 | 按完整消息新建任务，明确去向 |
| 课程冲突 | 查看原任务/保留原任务/忽略，不生成新任务或通知 |
| 可能重复 | 双方核对、逐字段选择、保持独立 |
| 不可接受 | 原因及已有处理入口，不绕过后端限制 |

- 固定确认区包含一句去向说明和准确操作；长错误完整展示并定位；必填缺失指出字段；提交忙碌并防重复；失败保留输入。

## 5. 批量、表单与并发

- 批量默认仅全选、数量、忽略、加入任务。至少选择一项后展开统一日期与建议日期选项；结果在结束后仍可见。
- 全选只含当前可见且合格项，支持半选；筛选移除不可见选择；折叠不清设置，采用建议须明确选择。
- 统一日期不沿用钟点；关联变更、课程冲突等按原规则单独核对。执行保持原锁定和队列；结果区分成功/保留/失败/未确认；超时停止剩余队列，迟到响应不切走当前事项。
- 新增/编辑保留标题、可输入新名称的课程候选列表、日期、可选钟点、时间类型和优先级；新增标题/课程/日期必填，编辑可清除课程/钟点。
- 完成/归档等在摘要操作区，普通编辑保存紧邻字段；待确认、新增、合并和拆分的主要提交固定底部。
- 表单外按钮通过form关联；点击/Enter仅发送一次；同步更新忙碌和禁用逻辑。
- 合并展示双方六字段差异、逐字段选择、保持独立、刷新及取消；窄栏上下比较。拆分继续选择证据及字段，缺日期/无原证据规则保留。
- 后台快照、换肤、课程选项变化、普通刷新保留草稿/焦点/光标/滚动；切页沿用会话草稿；显式取消新增清除草稿。
- 迟到保存不切页；版本冲突须刷新核对；超时用原请求身份重试。保存数据/偏好跨重启，草稿仍会话级。账号/代次变更和恢复沿用原隔离清理。

## 6. 图片、设置与原生界面

- 缩略图限高，多图稳定排列；下载/识别阶段和失败分别显示；仅合格失败可重试，忙碌禁用并保留表单。
- 原图对话框可按钮/Escape关闭并恢复焦点，账号/代次/恢复变化关闭旧图；保留转义、同源及账号校验；采用建议只填草稿。
- 设置完整内容最大约1000px，四分区：外观与桌面（主题/动画/透明度/挂载）；消息与课程（同步/失败群/置顶课程/重查/图片队列）；数据与备份（导出/恢复预览/取消/覆盖/位置/清理）；启动（自启动）。
- 分区用按钮在容器内滚动，URL/fragment不变，标题获得焦点；推送/换肤保留位置和课程草稿。
- 重查范围、清理结果、备份账号/日期/数量/原图完整性、恢复覆盖确认和恢复中写锁完整保留。
- 桌面卡片统一色彩/文字/控件，保留16 DIP圆角、透明外缘、优先级/日期/完成。提高小字；底色透明度0～100%，文字不透明，保留浅13%/深20%默认值。
- 拖动、缩放、约2 DIP吸附、拖离解除、布局保存、滚动位置、空隐藏、恢复位置、桌面父窗/非置顶/不激活不变。
- 标题栏浅色与米白协调，深色黑色，原生窗口控制不变。

- 阶段1：基准、需求与本计划、基线测试；阶段2：主题/框架/导航/滚动；阶段3：事项/详情/表单/图片/批量；阶段4：设置/WPF；阶段5：全部验证、截图、打包、更新、发布。
- 每个可独立交付阶段在相关测试通过后提交，最终交付前完整测试。
- 修改HTML容器、CSS角色变量、JS渲染与必要会话状态、图片样式、WPF卡片/标题栏、现有测试；不拆分整个业务脚本或建立新框架。
- 不增加公共API、桥命令、数据库迁移或备份格式；operation/parameters/账号/版本/代次、snapshot、set-appearance、偏好key、布局schema、图片协议保持兼容。
- 新增原文展开/设置定位仅会话UI状态。保留有效DOM及操作标识，删除节点时同步调用方。
- CSP与本地加载保留，页面URL稳定；原消息/课程/OCR/错误转义；视觉不发业务请求；普通推送不重建不相关表单；覆盖加载/忙碌/成功/失败/禁用。
