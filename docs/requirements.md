## 8. 实现技术路线

- 真实 Windows 应用采用 **C# WPF + WebView2**。
- 现有 HTML/CSS/JS 原型作为 WebView2 中的界面基础继续复用；WPF 负责窗口生命周期、系统托盘、登录后启动、本地持久化、NapCat 通信、工作区刷新及桌面卡片窗口层级。
- 桌面卡片的“仅在桌面显示”行为通过 WPF 配合 Windows 原生窗口 API 实现。
- RapidOCR 作为独立本地工作进程接入，由 WPF 调用并接收 OCR 结果，避免把 OCR 运行时绑定到界面进程。
- 当前已实现并验证 M1 时间、提醒和状态核心及 M2 本地识别、优先级和合成样本基线。M3 已有 WPF/WebView2 隐藏桥、本地 OCR 工作进程、真实 NapCat 只读接口及 Windows 探针代码和验证结果；通知探针已补齐自包含资源提取，受控冷启动回归及专用 URI 入口的用户实际点击通过，声音提醒已取消。本地 SQLite 收件箱、规则结果与正式事项生命周期已有实现和自动验证，AccountCandidateRouter 首轮本地候选自动路由、自动可靠关联变更与保守消息顺序协调已实现，ProcessAndRoutePending 在同一消息事务中提取及路由；正式应用骨架、基础页面及真实 QQ 到本地待确认的宿主已接入；正式桌面卡片首段已接入并验证；真实群课程确认后的任务验收、OCR 队列、真实桌面恢复/多屏及长期稳定性仍未完成，Windows 系统通知投递已取消。
- 首次启动显示简短引导，帮助完成初始连接、课程/群关联确认和桌面卡片预览；完成后登录 Windows 时在后台运行。
- 点击桌面卡片的“详情”或待确认事项，在主界面打开对应事项的原文、图片和变更记录。
- 事项较多时提供搜索和简单筛选，可按标题、课程、来源群或状态查找。
- 打开主界面时，若存在待确认事项则默认进入“待确认”页，否则进入“任务”页。
- 详情栏中的图片默认显示缩略图，点击后放大查看。
- OCR 文字默认折叠，用户点击“查看识别文字”后展开。
- OCR 识别出的图片日期以“建议日期”展示，只有用户确认后才正式用于提醒；用户可以修改或拒绝该建议。
