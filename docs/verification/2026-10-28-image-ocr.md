# 图片识别接入验证（2026-10-28）

当前已实现并通过开发验证；beta.12干净发布和本机部署正在准备。下列结果只记录实际执行范围。

## 实现范围

- 同步连接内只读`get_image`取回本地原图，按账号保存、校验格式/大小、原子写入及SHA256去重。
- 离线CPU RapidOCR顺序工作进程；解释器、锁定依赖及模型随包，游戏/同步/恢复/退出取消并等待。
- 原消息保持原样，OCR只提供证据与建议日期；新增遗漏仅待确认，不重放已有业务或人工历史。
- 原图缩略图、放大、默认折叠文字、失败重试和设置页待处理图片；纯图片失败也有入口。
- 原图备份、缺图范围、旧包兼容、恢复回滚、队列重开续跑和恢复代次隔离。

Native新场景核对受控原图实际加载和放大、折叠OCR、建议不预填正式日期、重试、人工正式日期确认、原消息字节语义不变和原图备份恢复。便携运行库验证中文空格路径、空PATH/伪造系统Python变量、禁socket及中文/长图/空图/坏图续跑；不需要系统Python。

失败及修复：旧审核整理误把OCR派生项的Ignored原分析用空正文重新建标题，已跳过这种旧整理。恢复测试默认SQLite连接池占用目录，显式禁池后独立通过。新图片队列读取失败不再污染已完成文字历史同步。Native发现WebView2虚拟目录映射未触发图片处理器，改为同源静态文件白名单和证据处理器后原图加载通过。一次旧备份提示断言随准确的新缺图文案更新；一次既有WebView2初始化瞬时失败如实留在本地日志，后续同入口通过。
