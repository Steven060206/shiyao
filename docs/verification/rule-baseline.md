## 适用表达与边界

- 日期支持 YYYY-MM-DD、YYYY/MM/DD、YYYY年M月D日、M月D日、M/D、今天/明天/后天、本周/这周/下周星期和下月明确日，以及阿拉伯数字钟点；相对表达始终使用原发送时刻及时区，无年份绝对日期使用发送年，仅日期不虚构钟点。
- 分析提交、完成、考试/参加、报名、催交、延期、取消和明确新要求；一条原消息最多一个完整业务候选，保留完整原文。多行动统一待确认（全部为普通通知时保留通知），不同日期或 Deadline/Start 角色不自动选定，需独立管理时由用户手动拆分。
- 正式候选依赖本账号、本群已确认的课程和对象；高影响变更还需本群可信发布者或已确认原发布者的明确引用续发，以及唯一目标。自愿报名/参加为通知。
- 模糊下周、今晚无钟点、未覆盖的中文钟点、冲突/非法日期、限定对象、未确认课程及来源/目标不足进入待确认。OCR 时间只作建议，旧引用不独立形成新行动。
- 复杂省略、同一动词多个交付物和跨句指代仍需真实样本增强，规则不能理解任意自然语言。本报告未验收真实课程名单提出、真实 OCR/QQ 接入、任务状态提交或通知投递；M2 只返回候选，不改用户状态。
