# 消息提纯可点击 Demo

用 Chrome 或 Edge 打开同目录的 [index.html](index.html)，或在文件夹里双击它。无需安装开发工具。

## 建议体验顺序

1. 在“待确认”打开大学物理事项，点击图片放大，展开“查看识别文字”。右侧内容可用滚轮滚动；填入建议日期、勾选确认后，点击右侧底部固定的“确认并加入任务”。其他事项若要转为任务，先将“事项类型”选为“任务”，补齐课程和日期后确认；保留为通知时，按钮显示“确认并保留为通知”。
2. 在“任务”完成一个事项，点击提示中的“撤销”；也可以到“已完成”中撤销。完成后 1 小时内有效。
3. 忽略一条待确认事项，通过状态筛选进入“最近忽略”，24 小时内可以撤销。
4. 归档一个任务，在任务页的“已归档”筛选中恢复。
5. 在任务详情展开“自定义此任务的提醒”，试试提前小时、前几天某时刻和关闭。
6. 展开“体验老师的新消息”，模拟延期、取消或新增要求。先修改正式时间再模拟延期，可以查看手动值冲突提示。
7. 点“新增任务”补录作业或考试；试试搜索、课程筛选、提醒预览和桌面卡片拖动／缩放。
8. 在“设置”切换浅色、纯黑深色或跟随系统，也可以减少动画。

## 自定义课程或分类

课程筛选和各表单中的“课程或分类”共用一份选项。展开任一课程下拉框，选择“＋ 自定义课程或分类…”，填写名称后保存。右侧新增后自动选中该名称，保存事项或确认任务后才修改事项所属课程；左侧新增只更新选项，保留当前筛选。手动新增任务也能使用相同的课程列表。

新增选项会立即同步，重复名称复用已有选项。取消新增或添加选项不会丢失当前表单中尚未提交的内容。

## 演示时间和保存

- 日期与优先级使用固定的 **2026-10-09 10:00（北京时间）**，便于体验今天截止、逾期和只有日期的情况。
- 完成与忽略的撤销期限使用真实经过时间；刷新不会重新计时。
- 事项、偏好、自定义课程／分类及卡片布局保存在此浏览器的本地存储。换浏览器、清理浏览器数据或移动文件后可能无法继续原来的演示进度。
- “重置示例”恢复示例事项和卡片布局，保留主题、声音等设置和自定义课程／分类。
